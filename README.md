# Ödev Takibim

Bu proje, Android Studio ile açılıp çalıştırılabilen, Kotlin + Jetpack Compose tabanlı bir öğrenci ödev takip uygulamasının başlangıç iskeletidir.

## Özellikler
- Çoklu öğrenci takibi
- Sınıf seçimi
- Ders seçimi
- Ders için konu başlıkları
- Ders için çoklu kaynak ekleme
- Ödev verilmesi sonrası farklı renkli kart görünümü
- Ödev tamamlandığında yeşil renge dönüşüm
- Teslim tarihinden 1 gün önce ve teslim günü hatırlatma planlaması

## Teknolojiler
- Kotlin
- Jetpack Compose
- Room Database
- WorkManager
- Material 3

## Android Studio ile açma
1. Android Studio'yu açın.
2. `Open` seçeneğine tıklayıp proje klasörünü seçin.
3. Gradle sync tamamlanana kadar bekleyin.
4. `Run` tuşuna basın.

## Notlar
- Android 13+ için bildirim izni gerekebilir.
- Uygulama başlangıç aşamasında temel ekran ve veri yapısı içermektedir.
- Sonraki aşamalarda öğrenciler, sınıflar, dersler, kaynaklar ve ödev yönetimi detaylandırılacaktır.
